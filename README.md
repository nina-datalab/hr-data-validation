# HR Data Processing & Validation Sample

複数の人事データを収集・加工し、月次差分の比較およびデータ間の整合性確認を行うサンプルプロジェクトです。

実務経験をもとに、架空データと簡略化した業務ロジックで再構成しています。

## 処理内容

1. 人事異動申請PDFから必要項目を抽出
2. 入社・退職・休職・復職情報を対象月ごとに統合
3. 前月・当月のDC加入者情報を比較し、差分を抽出
4. 人事情報とDC加入者情報を照合

## 使用技術

- Python
- pandas
- pdfplumber
- openpyxl
- python-dateutil

## 実行方法

```bash
python main.py
